1. RESUMEN Y PALABRAS CLAVE

Este informe describe los tres grandes grupos de software que usa una organización: el software de sistema, que administra el hardware; el software de programación, con el que se crean y mantienen otros programas; y el software de gestión, que automatiza procesos administrativos como la nómina o el control de asistencia. Se presentan definiciones, ejemplos vigentes, criterios para elegir un sistema de gestión de talento humano, obligaciones legales en Colombia (protección de datos, derechos de autor, nómina electrónica) y recomendaciones de seguridad. Se concluye que el técnico en Talento Humano no necesita programar, pero sí debe saber qué tipo de software requiere cada tarea, cómo configurar permisos y cómo evaluar una solución antes de adoptarla.

Palabras clave: software de gestión, software de sistema, software de programación, ERP, HRIS, licenciamiento, seguridad, talento humano.

2. INTRODUCCIÓN

Liquidar la nómina, registrar la asistencia o seleccionar personal se hace hoy con software. Sin embargo, no todo programa cumple la misma función: unos permiten que el computador funcione, otros sirven para crear aplicaciones y otros resuelven tareas del negocio. Confundirlos lleva a decisiones erradas, como comprar un sistema sin verificar si cumple la ley o instalar programas no autorizados.

2.1 Planteamiento del problema

¿Qué diferencia a los software de gestión, de programación y de sistema, y qué criterios debe usar un técnico de Talento Humano para elegirlos y usarlos de forma segura y legal?

2.2 Justificación

El software gestiona datos personales y financieros de los trabajadores, por lo que se rige por la Ley 1581 de 2012 y por normas de derechos de autor. Elegir y configurar bien reduce errores, costos y riesgos jurídicos.

2.3 Objetivos

General

Explicar los tipos de software de gestión, de programación y de sistema y su aplicación en Talento Humano.

Específicos
  • Definir y ejemplificar cada tipo.
  • Describir los módulos de un sistema de gestión de talento humano.
  • Proponer criterios de selección.
  • Identificar obligaciones legales y de seguridad.

3. MARCO CONCEPTUAL: QUÉ ES EL SOFTWARE

El software es el conjunto de programas, datos e instrucciones que indican al hardware qué hacer (Sommerville, 2016). Se puede ver como capas: cada una se apoya en la anterior.

Usuario (analista, jefe, empleado)
Software de gestión y otras aplicaciones
Software de programación (herramientas para crear programas)
Software de sistema (sistema operativo, controladores)
Hardware

La clasificación más difundida distingue software de sistema y software de aplicación (Laudon y Laudon, 2016; Stallings, 2016). El software de gestión es un tipo de software de aplicación y el de programación se considera un conjunto de herramientas de desarrollo. La guía de Byteon los presenta como tres tipos paralelos por fines didácticos.

Equivalencia con la guía: el «software de gestión de recursos robóticos» corresponde, en el mundo real, al software de gestión de recursos humanos o de capital humano (HRIS o HCM).

4. SOFTWARE DE GESTIÓN

Es el conjunto de aplicaciones que permite planificar, ejecutar y controlar procesos administrativos de una organización: contabilidad, ventas, inventario, talento humano, entre otros. Sus características principales son automatización de procesos, interfaz de uso sencillo, integración con otros sistemas, control de accesos por roles e informes para la decisión.

4.1 Tipos y ejemplos

TipoPara qué sirveEjemplos

CRM (relación con clientes)Gestiona contactos, oportunidades y ventas.Salesforce, HubSpot, Zoho CRM

Nota: el mercado cambia con rapidez. TradeGecko, citado en la guía, fue adquirida por Intuit y integrada a su oferta; verifique siempre que un producto siga vigente y con soporte antes de recomendarlo.

4.2 Módulos de un sistema de talento humano

Kavanagh y Johnson (2018) describen los sistemas de información de recursos humanos como herramientas que apoyan la adquisición, el almacenamiento, el análisis y la distribución de información de personal. Módulos habituales: reclutamiento y selección, administración de personal, nómina, control de asistencia, evaluación del desempeño, capacitación, seguridad y salud en el trabajo y autoservicio del empleado.

4.3 Modelos de despliegue

ModeloCaracterística
Local (on-premise)Se instala en servidores propios; mayor control, pero exige infraestructura y mantenimiento.
Nube (SaaS)Se usa por internet con suscripción; el proveedor mantiene la infraestructura (Mell y Grance, 2011).
HíbridoCombina módulos locales y en la nube.

4.4 Criterios de selección

La norma ISO/IEC 25010 define características de calidad del software, como adecuación funcional, eficiencia, compatibilidad, usabilidad, fiabilidad, seguridad, mantenibilidad y portabilidad (edición 2011). Para una decisión práctica se suman: cumplimiento legal colombiano, costo total de propiedad (licencias, implementación, soporte y capacitación), integración, calidad del soporte y plan de salida de los datos.

4.5 Obligaciones colombianas relevantes

  • Protección de datos: Ley 1581 de 2012 y reglamentación (Decreto 1074 de 2015); el software debe permitir autorización, acceso restringido y seguridad.
  • Nómina electrónica: la DIAN exige el documento soporte de pago de nómina electrónica (Resolución 000013 de 2021 y normas posteriores; verifique la versión vigente).
  • Seguridad social: aportes mediante la Planilla Integrada de Liquidación de Aportes (PILA).

5. SOFTWARE DE PROGRAMACIÓN

Es el conjunto de herramientas que permite escribir, traducir, probar y mantener programas en distintos lenguajes (Sommerville, 2016).

Nota: Atom, mencionado en la guía, fue descontinuado por GitHub a finales de 2022; hoy se recomiendan editores activos como Visual Studio Code.

5.1 ¿Qué relación tiene con Talento Humano?

El técnico rara vez desarrolla software completo, pero sí automatiza tareas con herramientas cercanas a la programación: macros en Excel con Visual Basic para Aplicaciones (VBA), consultas con Power Query, consultas SQL a una base de datos, scripts sencillos en Python o flujos automáticos de aplicaciones de bajo código (low-code). Esto permite, por ejemplo, consolidar cada mes los reportes de asistencia de varias áreas sin copiar y pegar a mano.

Buena práctica: toda automatización debe documentarse, probarse con datos ficticios y almacenarse con control de versiones o copias fechadas; no debe contener contraseñas escritas en el código.

6. SOFTWARE DE SISTEMA

Es el conjunto de programas que gestionan los recursos del hardware y ofrecen los servicios básicos para que funcionen los demás programas (Silberschatz et al., 2018).

CategoríaFunciónEjemplos
Sistema operativoAdministra procesador, memoria, archivos y dispositivos; ofrece la interfaz de usuario.Windows, macOS, Linux (Ubuntu), Android
Controladores (drivers)Permiten que el sistema operativo se comunique con periféricos.Controlador de impresora, de video o de audio
Utilidades y seguridadDiagnóstico, mantenimiento, copias de seguridad y protección.Administrador de tareas, Microsoft Defender, herramientas de respaldo
VirtualizaciónEjecuta varios sistemas operativos en un mismo equipo mediante un hipervisor (Popek y Goldberg, 1974).Hyper-V, VMware Workstation, VirtualBox
Gestores de bases de datosAlmacenan y consultan datos; algunos autores los ubican como software intermedio (middleware) o de aplicación (Date, 2004).MySQL, PostgreSQL, SQL Server, Oracle Database, MongoDB, Access

6.1 Vigencia y soporte

Los sistemas operativos tienen ciclo de vida: cuando termina el soporte, dejan de recibir actualizaciones de seguridad. Windows 10 llegó al fin de su soporte general el 14 de octubre de 2025, por lo que los equipos que manejan datos de personal deben migrar o acogerse a un programa de actualizaciones extendidas. Los ejemplos de versiones de la guía (Windows 10, macOS Ventura, Android 13) ilustran este envejecimiento.

Precaución: instale utilidades solo desde fuentes oficiales. En 2017 una versión legítima de CCleaner fue comprometida y distribuyó código malicioso (Cisco Talos, 2017).

8. LICENCIAMIENTO, LEGALIDAD Y SEGURIDAD

8.1 Licenciamiento

TipoCaracterísticaEjemplo
PropietarioUso bajo licencia; el código no se distribuye.Microsoft Office
Libre / código abiertoPermite usar, estudiar, modificar y compartir según su licencia (GPL, MIT, Apache).Linux, LibreOffice, Odoo Community
Suscripción (SaaS)Pago periódico por uso en la nube.Workday, BambooHR

«Libre» no siempre significa «gratis» y «gratis» no significa «libre». En Colombia el software está protegido por el derecho de autor (Ley 23 de 1982 y Decisión Andina 351 de 1993). La Ley 603 de 2000 exige que las sociedades informen en su informe de gestión sobre el cumplimiento de las normas de propiedad intelectual y derechos de autor, incluido el uso de software con licencia.

8.2 Seguridad del software

  • Instalar solo software con licencia y de fuentes oficiales; evitar copias no autorizadas, que pueden traer malware.
  • Mantener sistema operativo y aplicaciones actualizados.
  • Aplicar el principio de mínimo privilegio: cada rol ve solo lo necesario.
  • Usar autenticación robusta y registro de accesos.
  • Realizar copias de seguridad y probar su restauración.

11. CONCLUSIONES Y RECOMENDACIONES

Conclusiones

  • Los tres tipos de software cumplen funciones distintas y complementarias: el de sistema soporta, el de programación crea y el de gestión resuelve procesos.
  • Un sistema de gestión de talento humano integra reclutamiento, nómina, asistencia y desempeño, y debe cumplir la ley colombiana.
  • Elegir software exige comparar criterios ponderados, no solo precio.
  • El software obsoleto o sin licencia es una fuente de riesgo jurídico y de seguridad.
  • El técnico en Talento Humano puede automatizar tareas con macros o consultas sin ser programador profesional.

Recomendaciones

  • Mantener un inventario de software con versión, licencia y fecha de fin de soporte.
  • Definir roles y permisos antes de poner un sistema en producción.
  • Exigir al proveedor evidencia de cumplimiento (nómina electrónica, protección de datos, copias de seguridad).
  • Probar los cambios en un ambiente de prueba con datos ficticios.
  • Capacitar a los usuarios y documentar los procedimientos.
